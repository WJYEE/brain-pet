# Statling

6개의 짧은 미니게임을 통해 사용자의 능력 스탯을 발견하고, 게임 플레이와 함께 성장하는 개인화 펫을 만들어가는 웹 기반 게임 서비스입니다.

현재는 **6개 게임 → 6개 스탯 → MY STATUS → 레이더 차트**로 이어지는 첫 번째 MVP를 개발하고 있습니다.

## 핵심 스탯

Statling은 다음 6가지 스탯을 중심으로 구성됩니다.

* 기억력 (Memory)
* 집중력 (Focus)
* 순발력 (Reaction)
* 판단력 (Judgment)
* 공간감각 (Spatial)
* 추리력 (Reasoning)

각 스탯은 해당 능력과 연결된 짧은 미니게임의 플레이 기록을 기반으로 산출합니다.

## 핵심 사용자 경험

첫 방문 사용자는 6개의 게임을 순서대로 플레이합니다.

```text
게임 시작
↓
순발력
↓
기억력
↓
집중력
↓
판단력
↓
공간감각
↓
추리력
↓
6개 스탯 완성
↓
MY STATUS
↓
레이더 차트
```

첫 플레이에서는 6개의 게임이 끊기지 않고 이어지는 경험을 우선합니다.

## MVP v0.1

첫 번째 MVP에서는 다음 기능을 구현합니다.

* 6개의 미니게임
* 게임 간 연속 플레이 흐름
* 게임 수행 기록 및 점수 산출
* 6개 최종 스탯
* MY STATUS
* 레이더 차트 시각화
* 익명 사용자 기반 데이터 저장
* GA4 기반 사용자 행동 데이터 수집
* 웹 우선 반응형 UI

현재 MVP에서는 펫, XP, 레벨, 랭킹 등의 확장 기능은 구현하지 않습니다.

## 향후 확장 방향

6개의 스탯을 모두 발견한 이후에는 개인화된 펫이 부화하고, 사용자가 원하는 게임을 자유롭게 플레이하며 펫을 성장시키는 구조로 확장할 예정입니다.

```text
6개 스탯 완성
↓
알 부화
↓
개인화 펫 생성
↓
개별 게임 자유 플레이
↓
경험치 획득
↓
펫 성장
```

향후에는 펫이 특정 스탯의 게임을 요청하고, 해당 게임을 플레이하면 보너스 경험치를 받을 수 있는 시스템도 고려하고 있습니다.

추가 확장 기능:

* 개인화 펫
* 경험치 및 레벨
* 펫 성장 및 진화
* 펫 요청 기반 보너스 경험치
* 데일리 챌린지
* 랭킹
* 성장 기록
* 공유 기능
